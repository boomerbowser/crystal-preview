# Approved Crystal visual baseline

The user explicitly approved these four Crystal material studies on September 17, 2026: if any aspect of Crystal is visually out of line with these examples, something is wrong. Treat unexplained divergence as a defect, not as an acceptable style variation.

- [Material hierarchy](material-hierarchy.png): distinguish opaque Plastic, diffused Frost and clearer, elevated Resin.
- [Plastic foundation](plastic-foundation.png): contextual color without background detail passing through; readable inset content.
- [Haze over Resin](haze-over-resin.png): 80% content fill, feathered perimeter, crisp text and visible color beneath; a broad exposed Resin surround and convincing elevation.
- [Layered materials](layered-materials.png): substantial Frost diffusion and subtle grain, defined optical contours, soft protected content, and an elevated Resin control.

These are acceptance references, not replacement backgrounds or images to embed in the interactive preview. Preserve the original captures and manifest. The screenshots show approved material relationships, not a requirement that all products use their exact palette, wording or layout. Apply the same qualities in dark mode, other palettes, all components and every supported platform.

When changing any visual surface, capture the actual affected UI and compare it with the relevant baseline. Check translucency versus opacity, diffusion, color transmission, perimeter definition, feathering, elevation and foreground clarity. Inspect both a material study and its real component use; correct token numbers alone do not prove visual fidelity. If implementation or documentation conflicts with the approved appearance, investigate and correct the discrepancy rather than silently redefining the baseline.

Preserve documented reduced-motion, reduced-transparency, forced-color and accessibility adaptations. Do not reproduce an incidental screenshot artifact or sacrifice accessibility. Any intentional aesthetic departure needs the user's explicit approval; normal implementation fixes that restore this baseline do not.
